# Proyecto Fénix - Procesador de Usuarios 🚀

[![Java CI with Maven](https://github.com/edicxonlopezcolab/proyecto_fenix/actions/workflows/maven.yml/badge.svg)](https://github.com/edicxonlopezcolab/proyecto_fenix/actions/workflows/maven.yml)


Este proyecto es una aplicación Java gestionada con **Maven** que demuestra la implementación de buenas prácticas de desarrollo, incluyendo refactorización, pruebas unitarias y automatización.

## 🛠️ Tecnologías utilizadas
* **Java 17**: Lenguaje de programación principal.
* **Maven**: Gestión de dependencias y ciclo de vida del proyecto.
* **JUnit 5**: Framework para pruebas unitarias.
* **GitHub Actions**: Integración Continua (CI) para ejecución automática de tests.

## ⚙️ Integración Continua
El proyecto cuenta con un flujo de trabajo automatizado que se dispara con cada `push` a la rama principal. El servidor de GitHub:
1. Configura el entorno de Java.
2. Ejecuta `mvn test`.
3. Informa si los cambios son estables mediante el badge de estado superior.
